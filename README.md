# Rubia&Morena / LILIAN

Кандидат рабочей версии 1.1 мини-приложения: подбор по направлению, размеру и росту либо обращение о примерке в пространстве в Москве или Екатеринбурге. В обоих случаях открывается редактируемый черновик в Telegram; отправку выполняет сам пользователь. Параметры формы хранятся только в памяти открытой страницы.

Один статический сайт работает в Telegram и обычном браузере телефона или компьютера. Сервер заявок, регистрация и токен бота не требуются.

## Локальный запуск

Из каталога проекта запустите `python3 -m http.server 8080` и откройте `http://localhost:8080`. Для работы модулей нужен HTTP, открытие HTML через `file://` не поддерживается.

## Изменения

Тексты, получатели, три направления, два города и временные технические пределы роста находятся в `model.mjs`; интерфейс — в `index.html`, `app.js` и `styles.css`. В `assets/` находится оригинальный логотип и три облегчённые фотографии, предоставленные для этого приложения. Пропорции и цветовые профили фотографий сохранены; исходный логотип отображается через обрезку средствами CSS. Исходная рабочая версия 1.0 сохранена меткой `v1.0-working`.
