# Rubia&Morena / LILIAN

Тестовая версия 1.0.0 мини-приложения: выбор направления, примерного размера и роста, переход к редактируемому обращению в Telegram. Отправку выполняет сам пользователь. Параметры формы хранятся только в памяти открытой страницы.

Один статический сайт работает в Telegram и обычном браузере телефона или компьютера. Сервер заявок, регистрация и токен бота не требуются.

## Локальный запуск

Из каталога проекта запустите `python3 -m http.server 8080` и откройте `http://localhost:8080`. Для работы модулей нужен HTTP, открытие HTML через `file://` не поддерживается.

## Изменения

Тексты, получатель, три направления и временные технические пределы роста находятся в `model.mjs`; интерфейс — в `index.html`, `app.js` и `styles.css`. Четыре JPEG в `assets/` предоставлены для этого приложения и сохранены без изменения; исходный логотип отображается через обрезку средствами CSS.
